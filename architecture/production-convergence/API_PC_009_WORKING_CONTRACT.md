Capability outcome: implement default-off API command/query paths for canonical Quote creation, exact immutable quote-economics margin decisions, and exact-version Proposal review decisions against the existing Luzione Postgres relations, with explicit integer-money/currency invariants and P110 atomic evidence.

- Actor entrypoints: authenticated `POST|GET /api/v1/commands/quotes`, `POST|GET /api/v1/commands/quote-approvals`, and `POST|GET /api/v1/commands/proposal-reviews`. Mutations additionally require the global mutation switch, exact tenant allowlist membership, and the route capability.
- Expected end state: a draft Quote and its lines/economics snapshot commit once; a required margin exception is approved or rejected only by a credential-bound human actor holding the exact policy-role capability; a Proposal review is appended against the exact current proposal-document version, with approval additionally requiring verified provider readback, typed confirmation, and an eligible policy-role capability. Every accepted mutation atomically commits its canonical row(s) plus P110 receipt/event/outbox evidence and has tenant-bound authoritative readback.
- Current authoritative truth and writer: Postgres `quotes`, `quote_lines`, `quote_economics_versions`, `quote_margin_approval_records`, `commercial_case_proposal_document_versions`, and `commercial_case_proposal_review_versions` are operational truth. Luzione UI remains the active writer. This API cell is a transfer-pending dark path; it does not activate a second writer.
- Target write owner: CIBOTFLOW/Luzione-API only after an explicit tenant/cohort release, independent consumer proof, and rollback evidence. P15 proposal-document composition/rendering remains UI-owned and is not duplicated here.
- Readback: exact tenant-bound reads from the same Quote/economics/approval and Proposal document/review rows, followed by receipt causal readback when requested.
- Consumed contracts: `luzione-authority-subject/v0.1`, `luzione-command-ledger/v0.1`, `luzione-causal-readback/v0.1`, `luzione-lead-commercial-case/v0.1`, UI P15/P16 proposal contracts, and the observed Quote economics/approval schema.

- Acceptance proof: parser/version/money/currency sensitivity; human/capability/typed-confirmation denial; stale economics and superseded proposal denial; exact replay and changed-payload conflict; transactional rollback; cross-tenant denial; canonical readback; fresh and observed UI-shaped migration; full repository gates.
