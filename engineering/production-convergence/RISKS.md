# Production Convergence Risks

1. Current Tier-1 UI writers/table shapes are not independently inventoried in this repository.
2. Most Tier-1 mutation owners remain unresolved in current evidence.
3. P110/P111 migration history and ownership transfer are absent from merged main.
4. Durable command/workflow/receipt contracts exist partly as libraries but lack one current universal Postgres runtime path.
5. UI and Sultan consumer compatibility is unproven.
6. Preview/production release identity, rollback and authoritative journey evidence must be observed after merge.
7. Provider configuration can be mistaken for reachability unless observed/readback states remain distinct.
