# Production Gap Register Contract

The private register records exact systems and evidence. Every material gap has:

- a stable ID, severity, owner and evidence label;
- affected tenant/capability without customer data in the public record;
- current symptom and canonical cause;
- safe containment and rollback;
- exit evidence and exact verifier;
- dependent releases and expiry/review date.

Mandatory gap classes are migration parity, runtime schema failures, tenant and
identity ambiguity, fragmented connection/secrets, command/workflow activation,
deployment visibility, verified database TLS, operator identity, proposal
confidentiality, provider readback, retries/dead letters/reconciliation, model
cost, governed learning, CI availability and unresolved security advisories.

A gap is closed only by executable evidence. Deferred infrastructure stays
`BLOCKED` or `DEGRADED`; it is never converted to a passing capability claim.
